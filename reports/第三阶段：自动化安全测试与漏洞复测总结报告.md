## 2. 第三阶段目标

第三阶段是在前两个阶段完成基础安全审计、动态验证和漏洞整改的基础上，进一步建立可重复执行的自动化安全测试体系。

本阶段主要目标：

1. 将部分人工安全测试转化为自动化测试。
2. 建立身份认证、JWT 异常处理和对象级授权测试。
3. 对前期发现的安全问题进行回归验证。
4. 通过依赖漏洞扫描识别第三方组件风险。
5. 完成 Spring Boot 大版本升级及兼容性复测。
6. 整理项目审计证据、测试报告和整改记录。
7. 形成完整的安全审计与复测交付成果。

## 4. 自动化安全测试体系

本阶段建立了 T1–T4 四组自动化安全测试。

### 4.1 测试分组

| 测试编号 | 测试主题                   | 主要验证内容                                                 |
| -------- | -------------------------- | ------------------------------------------------------------ |
| T1       | 安全回归测试基线           | 匿名访问控制、健康检查、无效 JWT、登录认证                   |
| T2       | JWT 身份认证测试           | 正确账号密码登录、有效 JWT 访问受保护接口                    |
| T3       | JWT 异常与过期测试         | 伪造 Token、篡改 Payload、篡改 Signature、过期 Token、错误 Authorization 格式 |
| T4       | JWT 权限控制与越权访问测试 | 跨用户读取、列表、邮箱查询、姓名搜索、修改、删除及伪造 ownerId |

### 4.3 身份认证测试

验证匿名用户访问受保护接口时无法正常获取用户资料。

验证正确账号密码能够完成登录，并获得 JWT。

测试重点：

- 未提供 Token。
- 提供有效 Token。
- 提供无效 Token。
- 登录认证成功。
- 受保护接口认证要求。

### 4.4 JWT 异常测试

验证以下异常 Token 均被系统拒绝：

- 完全伪造的 Token。
- Payload 被篡改的 Token。
- Signature 被篡改的 Token。
- 已经过期但签名合法的 Token。
- 错误 Authorization 格式。

本轮对应异常场景均返回 HTTP 401。

### 4.5 对象级授权与越权访问测试

通过创建两个独立普通用户，验证不同用户之间的数据访问隔离。

覆盖场景：

- 跨用户读取资料。
- 跨用户获取资料列表。
- 跨用户邮箱查询。
- 跨用户姓名搜索。
- 跨用户修改资料。
- 跨用户删除资料。
- 创建资料时伪造 ownerId。

上述测试均达到预期结果。

主要配置：

### 6.3 扫描结果分析

但需要注意：

1. 升级前后扫描时间不同。
2. NVD 漏洞数据库会持续更新。
3. 依赖树在 Spring Boot 大版本升级后发生变化。
4. 漏洞记录数量变化不能完全归因于本次依赖升级。

因此，本次扫描结论应准确表述为：

**在当前依赖版本、Dependency-Check 扫描规则和漏洞数据库条件下，未发现已识别的 CVE 漏洞。**

扫描结果不代表项目不存在未知漏洞、业务逻辑漏洞或其他安全风险。
